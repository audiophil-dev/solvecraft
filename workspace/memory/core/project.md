# Project

SolidCraft is a pure-Rust parametric CAD application. This fork preserves upstream v0.15.0 (`fa691707`) and carries a native-link STEP cone-classification repair. See `docs/fork-maintenance.md` for the maintained fork record and MCP trial instructions; `AGENTS.md` defines repository engineering and licensing rules.

The writable fork remote is `fork`; use `git remote -v` for its current URL. `origin` is upstream. The upgrade branch is `upgrade/v0.15.0-cone-repair`; the original repair branch is `fix/step-out-cone-classification-band`.
